# tapbeam

Tap config/beam key checks for twelve-factor services.

**Site:** https://theworker02.github.io/tapbeam/

## Install / run

```bash
git clone https://github.com/theworker02/tapbeam.git
cd tapbeam
node src/cli.js
node --test
```
